# 项目长期记忆 — "山海一叶"茶文化交互式数据叙事网站

## 项目定位

以中国茶文化为主题的交互式数据叙事网站，地图 + 时间轴 + 统计图表 + 信息卡讲述茶叶从自然生长到全球传播的过程。传统东方审美 + 现代数据可视化。技术栈：Vue3 + vue-router(hash) + Leaflet(自定 Albers CRS) + ECharts + D3/topojson + GSAP。

结构：/prologue、/ch1~ch6、/epilogue 共 8 页。章节组件在 `src/components/Chapter1Map.vue`~`Chapter6Map.vue`，配置在 `src/config/ch1~ch5.js`。全局样式与 CSS 变量在 `src/assets/style.css`（--c-olive #516D33、--c-gold #B28F4C、--font-body 等）。

## 固定视觉与交互规范（用户确认，2026-08-27）

### 配色（低饱和、自然温润，图表色从该色系派生）
- 主绿 #516D33；辅助绿 #7F985D；浅绿 #A8B68D
- 茶金 #B28F4C；浅茶金 #D8CDAF
- 页面米白 #F7F4EB；浅米灰 #D8D2C2
- 深正文 #34452A；强调红仅用于下降/峰值等警示，保持低饱和
- 禁止：默认蓝、荧光色、彩虹色带、高饱和红绿对比、复杂渐变

### 字体
- 章节开场标题/核心艺术标题：权衡度量体；图表标题：正文楷体（不用艺术字体）
- 正文/信息卡/图例/坐标轴/地名/悬浮提示：项目现有楷体正文（--font-body, KaiTi, STKaiti, serif; font-style: normal）
- 英文数字继承正文字体栈；不使用斜体

### 字号
- 六章开场主标题 100px；开场序号 80px（权衡度量体）
- 常规页面标题约 28px；导航/翻页按钮/信息卡正文小四级；图例/图表标题五号级
- 坐标轴标签以可读性为准

### 版式
- 地图/背景铺满，控件悬浮叠加；不切割成割裂色块
- 信息卡：米白半透明背景 + 细茶金或浅绿边框 + 柔和阴影圆角
- 图例/说明框/转盘沿页面边缘成列，不遮挡地图
- 图表宽松居中；图片横构图完整展示

### 地图原则
- 保持既有投影（Albers 中央经线 105°E）、中心与边界风格；不改动真实路线坐标、省级中心、文化点位置
- 行政区浅米色/半透明填充，避免大面积高饱和设色
- 路线动画平滑，视角变化稳定；节点固定，动画用透明度变化（禁飞入/弹跳/随机位移）
- 缩略图与主图共用坐标、投影、图层、色彩逻辑

### 交互原则
- 动画缓慢连贯，避免跳变抽帧
- 悬浮=预览，点击=锁定/进入详情；关闭详情恢复进入前状态
- 严格区分：无数据 / 真实零值 / 暂无可比数据；无有效数据区域不显示符号、不进空白详情
- 选年份不重置当前选区或地图视角
- 不重复初始化地图实例，优先更新已有图层

### 非任务要求不改动的范围
全站导航与底部翻页按钮；页面整体布局与响应式结构；地图投影/底图风格/行政边界；已确认路线与节点坐标；其他章节；全站字体体系与基础配色；原始统计数据；已有信息卡/图例/交互的整体视觉风格。
